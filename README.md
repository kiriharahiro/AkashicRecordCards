# Akashic Record Cards

アカシックレコードカード（リーディングカード）のWebビューワーアプリです。

## プロジェクトについて
本プロジェクトは、アカシックレコードカードのデータをJSON形式で保持し、Web上でインタラクティブにカードを閲覧・操作できるアプリケーションです。
