# Akashic Record Cards

アカシックレコードカード（リーディングカード）のWebビューワーアプリです。

## プロジェクトについて
本プロジェクトは、ゲリー・ボーネル氏のアカシックレコードカードをWeb上でインタラクティブに展開・閲覧・リーディングできる Single Page Application (SPA) です。

### 🔮 バージョン 4.0 (v4) の新機能
- **公式3種スプレッド**: ゲリー・ボーネル氏の体系に基づく「1枚引き（気づき）」「4枚スプレッド（洞察）」「9枚スプレッド（多次元）」を厳格に実装。
- **問い・探求テーマ設定**: リーディング開始前に魂のテーマ（自己探求・現実の課題・未来の可能性など）を設定し、シンクロニシティの焦点を合わせる対話的ステップ。
- **統合リーディング解説（Synthesis Engine）**: 引き当てられたカード群を有機的に結びつけた総合ガイダンス（魂の現在地・ブロックの変容・日常の実践処方箋）を動的に自動生成。
- **アカシックAIメンター（Google Gemini 3.8 Flash連携）**: カード展開後、AIメンターからパーソナライズされた深層神託メッセージを受信し、追加のフォローアップ対話が可能（※APIキーはブラウザローカル内のみで安全に保持）。
- **リーディング履歴＆拡張I/O**: 過去のリーディング記録の保存・蓄積、AIプロンプトのワンクリックコピー、Markdownコピー、JSONエクスポート。
