# Akashic Record Card v3 仕様書および操作手順書

## 1. システム概要
「Akashic Record Card」は、ウェブブラウザ上で手軽にオラクルカード（アカシックリーディング）を展開し、直感的なアニメーションやサウンドと共にリーディングを行える Single Page Application (SPA) です。

v3（バージョン3）では、**完全な英語版（index_en.html）の追加**、**Googleスプレッドシートを通じたリアルタイムデータ同期機能**、および**セキュリティに配慮した設計**が導入され、GitHub Pagesなどの静的ホスティングサービスで安全かつ簡単に全世界へ公開できるようになりました。

---

## 2. システムアーキテクチャ（仕様）

本システムは、サーバーサイドのデータベースを必要としない「クライアント完結型」の設計を採用しています。

- **コア技術**: HTML5, CSS3, Vanilla JavaScript
- **データソース**: 
  - **ローカル（初期状態）**: Pythonスクリプトにより、あらかじめカードデータ（JSON形式）をHTML内に直接埋め込んで生成。
  - **オンライン（同期機能）**: ユーザーが指定したGoogleスプレッドシートの公開URLからCSV形式でデータを取得し、画面上のテキストを動的に上書き。
- **ビルドシステム**: uild_html.py（日本語版）および uild_html_en.py（英語版）を用いて、データとHTMLテンプレートを結合し、最終的な index.html および index_en.html を出力します。

## 3. 主要機能一覧

### 3.1. スプレッド（配置）選択とシャッフル
ユーザーは以下の3種類のスプレッドからレイアウトを選択できます。
- **1枚引き（One Card）**: 今日のテーマやシンプルなメッセージ用。
- **3枚引き（Three Cards）**: 過去・現在・未来、あるいは問題・原因・対策などのベーシックなリーディング用。
- **9枚引き（Nine Cards）**: 深層心理や全体像を読み解く詳細なリーディング用。

「カードを引く（Shuffle & Draw）」ボタンを押すと、コズミックなサウンドエフェクトと共に、カードが裏向きの状態でシャッフルされ、所定の位置に展開されます。カードの正位置・逆位置はランダムで決定されます。

### 3.2. カード詳細表示（モーダルウィンドウ）
展開された裏向きのカードをクリックすると、カードが表返り（フリップアニメーション）、詳細解説のモーダルウィンドウが開きます。
表示されるデータ：
- カード番号とテーマ（例：Gateway）
- 霊的意義（Spiritual Meaning）
- リーディングメッセージ（正位置または逆位置のテキスト）
- 霊的なレベル（Spiritual Level） / 日常のレベル（Daily Level）
- 詳細解説テキスト（Description）

### 3.3. 呼吸法タイマー機能
心を落ち着かせてリーディングに臨むためのタイマー機能です。
- 「吸う（Inhale）」「止める（Hold）」「吐く（Exhale）」のガイドテキストとともにプログレスバーがアニメーションします。
- 一時停止・再開が可能です。

### 3.4. データベース同期機能（Sync Settings）
画面内の「歯車アイコン（⚙️）」から設定画面を開くことができます。
ここにGoogleスプレッドシートの共有URLを入力して同期（Sync）することで、**HTMLファイルを書き換えることなく、最新のカードテキストをスプレッドシートから直接読み込んで表示**することが可能です。
- ※スプレッドシートは「リンクを知っている全員が閲覧可」になっている必要があります。
- ※英語版はスプレッドシートの「一番左にあるシート（タブ）」のデータを読み込みます。

## 4. 操作手順・メンテナンスガイド

### A. 一般ユーザーの操作手順（利用方法）
1. GitHub Pages等で公開された index_en.html （または index.html）のURLにアクセスします。
2. 画面上部のセレクトボックスから引く枚数（Layout）を選択します。
3. 「Shuffle & Draw」ボタンをクリックし、カードを展開します。
4. 画面上に伏せられたカードを任意の順番でクリックし、メッセージを読み取ります。
5. 心を落ち着けたい場合は、右上の「Timer」ボタンから呼吸法タイマーを利用します。

### B. 管理者向け：カードのテキストデータを更新する方法

データを更新する方法は「オンライン（スプレッドシート）」と「ローカル（HTML再生成）」の2種類があります。用途に合わせて使い分けてください。

#### 方法1：スプレッドシートで手軽に更新する（おすすめ）
HTML自体は更新せず、公開中のアプリのテキストのみを最新化したい場合に便利です。
1. 管理用のGoogleスプレッドシート（例：AkashicRecordCards_ENG）を開き、テキストを直接編集します。
2. ブラウザで公開中のアプリを開き、歯車アイコン（⚙️）をクリックします。
3. スプレッドシートのURLを入力して「Sync」ボタンを押します。
4. ※この設定はユーザーのブラウザに保存されるため、次回アクセス時も自動でスプレッドシートの最新データが反映されます。

#### 方法2：ローカルでHTMLファイル自体を作り直す（完全アップデート）
アプリの初期状態（デフォルト）のデータを書き換えたい場合に使用します。
1. .03 フォルダ内にある cards_data_en.json （または cards_data.json）をテキストエディタで開き、文章を編集して上書き保存します。
2. コマンドプロンプトまたはPowerShellで .03 フォルダに移動し、以下のコマンドを実行します。
   `ash
   # 英語版を更新する場合
   python build_html_en.py
   
   # 日本語版を更新する場合
   python build_html.py
   `
3. スクリプトが実行されると、最新のテキストが埋め込まれた index_en.html が出力されます。
4. 出力されたHTMLファイルを GitHub にコミット＆プッシュして公開します。

## 5. セキュリティと公開設定について
- 本システムは静的ファイル（HTML/CSS/JS）のみで構成されており、サーバーサイドの脆弱性（SQLインジェクション等）は発生しません。
- スクリプト内のパスはすべて「相対パス」で指定されているため、管理者のパソコンのローカルフォルダ構造が漏洩することはありません。
- Googleスプレッドシート連携機能は「読み取り専用（公開状態）」のデータにのみアクセスするため、スプレッドシートが改ざんされるリスクはありません。
