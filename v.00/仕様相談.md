# アカシックレコード総合リーディングアプリ 開発・仕様相談記録（v.00 凍結版）

本ドキュメントは、ゲリー・ボーネル氏（作者）の意図通りの本格的かつ神秘的な作法で行える「アカシックレコード総合リーディングアプリ（v.00）」の開発における、すべての仕様決定、フィードバック、および改善プロセスの全歴史を漏らさず記録したものです。

---

## 1. 開発の背景と目的
ユーザー様からご提供いただいた書籍解説PDF『AkashiRecordCard.pdf』および全33枚のカード情報が記録されたスプレッドシートデータに基づき、お使いのパソコンやスマートフォンのブラウザでダブルクリックするだけで完璧に動作する、神秘的で最高品質のSPA（シングルページアプリケーション）を構築することを目的としました。

---

## 2. 仕様相談と開発の全歴史（経緯）

### 【第1期】初期開発：シンプルなドロー機能
* **ユーザー要望（初期）**: 共有ドライブへのアクセス権限設定、およびカード情報の読み込み。
* **実装内容**:
  - スプレッドシートから全33枚のカードデータ（タイトル、霊的意義、正逆位置の意味、解説、レベル等）を抽出し、クレンジングしたJSONデータを統合。
  - Googleドライブの共有画像URLを、ブラウザで直接表示可能なプレビュー用直リンク（`https://lh3.googleusercontent.com/d/[ID]`）へ自動変換するスクリプトを搭載。
  - 1枚をランダムに引き当てる「Pick One（一枚引き）」を実装。
* **ユーザー要望7**: 「1枚引きのみを表示するようにしてほしい（Pick One）」。➔ 改修完了。
* **ユーザー要望8**: 「テーマカードとセルフカードを引く『Pick Two』のメニューを追加して動くようにしてほしい」。➔ テーマとセルフの2枚引き機能、および手動でカードを入力する「Entry Numbers」とカード一覧「Cards」を追加。

---

### 【第2期】本格化：PDFに基づくゲリー・ボーネル氏の意図の完全再現
* **ユーザー要望9**: 「解説（PDF）にある通り、すべてのケースを網羅して実行できるよう、適切なデザインを組み合わせ、作者の意図通りにリーディング出来るよう、ガイダンスを付けてロジックを作ってください」。
* **大改修の設計・実装（総合リーディングアプリへの劇的進化）**:
  1. **🧘 Meditation（準備フェーズ）の導入**:
     - 息を吸う（7秒）➔ 止める（5秒）➔ 吐く（12秒）の比率呼吸瞑想タイマーを実装。
     - 呼吸のリズムと同期して美しいオーラのように膨張・収縮するグラデーションリングをデザイン.
     - Web Audio API を用いて、外部読み込み不要で「チク・タク」と鳴り響く電子秒針音（フェーズで音程が微変）を搭載。
  2. **🔮 Reading（リーディングボード）の導入**:
     - 最初にスプレッドの中心軸（中立）となる「セルフカード」を選択（一覧から手動、またはランダムでドロー）するステップを構築。
     - ゲリー氏推奨の3大スプレッドの完全実装：
       * **1枚引き (今日のテーマ)**: セルフカードの上にテーマを1枚配置。
       * **4枚スプレッド (洞察)**: セルフ（中心）、障害（下・重ねて横向き）、過去の態度（左）、今すぐ受ける影響（右）、最も起こりうる結果（上）を十字架配置。
       * **9枚スプレッド (多次元レベル)**: 十字スプレッドに加えて、右側に「内的葛藤」「セルフイメージ」「外側の葛藤」「希望と恐れ」「最終結果」の5段スタックを絶対配置。
     - **障害（ブロック）カードの横向き（90度）配置**: PDFの指示通り、スプレッド2枚目の障害カードをセルフの下に横向きで重ね、正位置（左が上）/逆位置（右が上）で美しく回転配置。
     - **3Dフリップめくり演出**: 配られたカードを裏向きでセットし、クリックで「カチッ」と音を鳴らしながら3D回転してオープンする演出。
     - **リアルタイム詳細連動パネル**: 選択したスロットの意味と、カードの正逆メッセージ、解説文が下部に連動表示される仕組み。
  3. **📝 Entry（手動入力）の拡張**:
     - 各スロット（セルフ、障害、過去、現在など）に任意のカードと正逆を設定し、スプレッドボード上に直接展開できる機能。
  4. **📖 Cards（カード図鑑）**:
     - インクリメンタル検索（タイトル、番号、霊的意義での部分一致）と詳細解説モーダル。
  5. **🛡️ ローカル起動フリーズバグ対策**:
     - `DOMContentLoaded` のタイミングバグを回避するため、`document.readyState` 監視と `try-catch` による安全な起動ロジック（`initializeApp`）を実装。

### 【第3期】バグ修正 ＆ さらなるUI/UXの極限への磨き込み
最新の検証およびユーザー様からのフィードバックにより、以下の不具合修正と5つの極上なUI/UX改善を行いました。

* **不具合修正：二重配列バグの解消**:
  - `CARDS_DATA` にプレースホルダーを流し込む際、外側に余分な括弧 `[]` がついていたため二重配列となり、起動時に「画像がUndefinedになる」「ボタンが動かない」状態になっていたバグを特定し、修正しました。
* **改善要望①：シャッフルカード枚数の動的変化と舞い踊る演出**:
  - 【以前】シャッフル中のカードの影が3枚固定で左右に動くだけだった。
  - 【改善】選択したスプレッド（1枚引きは2枚、4枚は5枚、9枚は10枚）に合わせて、シャッフル中のカード枚数が動的に変化。さらに、各カードに異なる動き（上下左右斜め）と時間差（ディレイ）を与え、エレガントに舞い踊る多方向シャッフルアニメーションに進化させました。
* **改善要望②：選択されたカード枠のゴールド太枠化**:
  - 【改善】セルフカード選択時や、リーディングボード上で現在アクティブになっているカードスロットの枠線を **2.5px solid のゴールド太枠** に強化し、Glow（光彩）も強めて視認性を飛躍的に高めました。
* **改善要望③：スクロール挙動のスマート化（3倍遅い優雅なスムーズスクロール）**:
  - 【改善】カードが配られた直後、および手動設定から展開した直後は、勝手に画面が下へスクロールするのを防止。まずは「スプレッド配置図全体」が画面中央に留まります。
  - 【改良】配置図からカードをクリック（タップ）した際、ブラウザ標準の素早いスクロールではなく、JavaScriptのカスタムイージングアニメーション関数 **`slowScrollTo`** を新たに自作・実装。**通常の3倍の時間をかけ（約1.8秒）、ゆっくりと滑らかに下部の詳細明細パネルへスクロール移動する、映画のように優雅で心地よいプレミアム体験**に昇華させました。
* **改善要望④：正逆確率の厳格化と逆位置専用イメージ＋CSS反転の二重保護**:
  - 【改善】正位置と逆位置が正確に **5:5（50%）の確率** で出現するように調整。
  - 【再検証での発見】元のデータベースシートのH列（正位置）とI列（逆位置）には、**それぞれ逆向きに美しくデザインされた専用の画像URLが最初から個別に準備されていた**ことが発覚。
  - 【対策】逆位置（isPositive = false）の際は、データベースにある逆位置専用イメージ（`url_reverse`）を直接ロードするようにロジックを構成。さらに、一部のカードで画像の実体が回転していない場合や、ブラウザの3Dフリップ（rotateY）との表示干渉を完全に防ぎきり、**どのような環境でも確実に逆向き（天地逆さま）で表示されるよう、CSS側に `transform: scale(-1) !important` と `display: block !important` を重ねて適用する「最強の二重保護仕様」**を実装。これにより、100%確実に逆位置のデザインが描画されます（障害の逆位置は90度＋180度で綺麗な270度になります）。
* **改善要望⑤：解説文の「読点（。）」での自動改行**:
  - 【改善】詳細解説およびモーダルの解説について、読点「。」の後に自動で改行を挿入する自動整形ロジック `formatDescription` をJavaScript側に搭載。長文でもスッキリと息を呑むような読みやすさを実現しました。
